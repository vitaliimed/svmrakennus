| Ресурс | Значение |
|---|---|

| Runtime account | `svm-runtime@project-c6c1d639-9739-4837-9c8.iam.gserviceaccount.com` |
| Именованная Firestore | `svm-rakennus` |
| Namespace документов | `svm_rakennus_site` |
| Закрытый bucket | `project-c6c1d639-9739-4837-9c8-svm-rakennus-media` |
| Secret Manager | `svm-rakennus-session`, `svm-rakennus-admin-password` |

`bootstrap-gcloud.sh` использует существующие аккаунты; другие аккаунты не создаёт. Build получает `roles/run.builder`; runtime — `roles/datastore.user`, `roles/storage.objectAdmin` только на bucket сайта и доступ только к секретам сайта. Все облачные команды указывают проект явно. Повторный запуск сохраняет базу, файлы и секреты. Firestore создаётся с защитой от удаления, bucket — с запретом публичного доступа и versioning.

Пароль администратора вводится дважды без отображения; минимум 12 символов. Скрипт не предлагает пароль `12345`; в локальном запуске он пока используется по умолчанию. В `.deployment.env` сохраняются ссылки на ресурсы, без паролей, с правами файла `0600`.

Runtime имеет права на Firestore проекта; отдельное ограничение IAM на именованную базу в этом выпуске не настраивается. Versioning/soft delete могут сохранять старые версии файлов и создавать платные объёмы: срок хранения резервных версий задаётся отдельно.

## Следующий запуск в Cloud Shell

После получения этой версии исходников:

```bash
cd /home/medynikv/sites/svm-rakennus
bash scripts/verify.sh
bash scripts/check-client-project.sh project-c6c1d639-9739-4837-9c8
bash scripts/bootstrap-gcloud.sh project-c6c1d639-9739-4837-9c8
```

Это подготовка ресурсов. Сайт не развёртывается. Проверка владельца платёжных реквизитов остаётся у клиента и не требует доступа оператора к карточным данным. Отсутствие прав просмотра самого billing account не мешает прочитать привязку billing на уровне проекта.

Для отдельного закрытого просмотра:

```bash
bash scripts/deploy-cloud-run.sh --private
gcloud run services proxy svm-rakennus \
  --project project-c6c1d639-9739-4837-9c8 \
  --region europe-north1 --port 8080
```

Откройте Cloud Shell Web Preview на порту 8080. Для проверок из другого терминала можно обращаться к выведенному URL Cloud Run с `bash scripts/smoke-check.sh https://SERVICE_URL --authenticated`. Веб-просмотр через Google IAM и пароль кабинета — два отдельных уровня доступа.

Закрытый запуск всё равно создаёт сервис и использует Cloud Build/Firestore/Storage; это реальные облачные ресурсы. Минимум экземпляров 0, максимум 3; 1 vCPU, 1 GiB, concurrency 8, timeout 120 секунд. Нулевая минимальная ёмкость не означает отсутствия всех расходов.
