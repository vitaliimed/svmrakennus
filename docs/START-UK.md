# SVM Rakennus: швидкий запуск

Сайт фінською за замовчуванням, друга мова англійська. Кабінет українською; поруч із фінськими текстами є редаговані переклади й словник термінів.

## На комп’ютері

Розпакуйте архів і встановіть Go. У терміналі відкрийте папку `svm-rakennus`:

```bash
go run ./cmd/server
```

Сайт: `http://localhost:8080/fi/`; кабінет: `http://localhost:8080/admin`. Початковий пароль: `12345`. Змінюється в «Система». Локальні дані залишаються в `data/` після перезапуску.

## Google Cloud Run

Потрібні проєкт Google Cloud з billing, Cloud Shell і права адміністратора для створення ресурсів. Завантажте архів і виконайте з папки, де він лежить:

```bash
unzip SVM-Rakennus-Go-CloudRun.zip
cd svm-rakennus
bash scripts/bootstrap-gcloud.sh YOUR_PROJECT_ID
bash scripts/deploy-cloud-run.sh
bash scripts/configure-email.sh
```

Замініть `YOUR_PROJECT_ID` реальним ID. За замовчуванням сервіс має назву `svm-rakennus`, регіон `europe-north1`. Firestore і Cloud Storage зберігають контент та файли між випусками. Скрипти не переналаштовують інші сервіси.

## Початкове заповнення

У «Компанія та контакти» введіть підтверджені реквізити, телефон, email, домен, контактну особу й завантажте ваш логотип. У «Тексти та сторінки» відредагуйте фінські тексти, українські переклади для себе та англійську версію.

У «Портфоліо» замініть демонстраційні об’єкти реальними фото й описами. У «Документи» та «Відгуки» додайте справжні матеріали та ввімкніть відповідні блоки. Відгуки й сертифікати не вигадані; розділи готові для вашого наповнення.

У «Система» перевірте SMTP і змініть пароль. У «Аналітика та реклама» введіть потрібні ID та мітки конверсій. Потім перевірте тестове звернення й доставку email. Наприкінці підготуйте юридичні тексти, вимкніть демонстраційний режим та дозвольте індексацію в SEO.

Українські підказки не є автоматичним перекладом: після зміни фінської версії оновлюйте їх вручну. Публічного маршруту `/uk/` немає.

Докладна інструкція російською: `GUIDE-RU.md` та `SVM-Rakennus-Guide-RU.pdf`. Автономне HTML-прев’ю показує дизайн без запуску Go; звернення, SMTP й справжній кабінет працюють у серверному проєкті.
