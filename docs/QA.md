# Проверки выпуска

Дата: 10 октября 2026. Основная среда проверки: Linux, Go 1.22.2, Node.js, Python 3.12. Production Dockerfile использует Go 1.26.

## Автоматические проверки

| Проверка | Покрытие |
|---|---|
| Go build / vet | Все пакеты сервера и встроенные шаблоны |
| Go tests / race | Авторизация, CSRF, смена пароля, конфликтные сохранения, сохранность данных |
| HTML render tests | EN/FI главная, услуги, объект, legal pages, thank-you и admin |
| Upload tests | Реальный WebP, корректный PNG, отказ некорректному заголовку, приватный доступ |
| Email failure | Заявка остаётся в базе, повтор email меняет статус |
| Idempotency | Повтор HTTP-запроса не создаёт вторую заявку или письмо |
| Media delete | Используемый файл нельзя удалить; вложения очищаются с заявкой |
| Redirects | Изменение slug даёт 301, циклы отвергаются |
| Cloud REST fixture | Bearer token, его cache, сериализация и updateTime guard |
| JS syntax | admin.js, admin-help.js, site.js, tracking.js |
| Tracking tests | Consent gates, allowlist без PII, dedup, очереди платформ, GTM separation, withdrawal |
| Content check | 129 полей EN/FI/UK, slug, файлы, launch defaults, SEO markup |
| Shell syntax | Все .sh скрипты |

Команды и протокол итоговой проверки поставляются в `scripts/verify.sh` и `docs/verification.txt`.

## Дополнительные проверки версии SVM Rakennus

- Основная версия fi; корневой redirect сохраняет кампанию, x-default ведёт на соответствующую FI-страницу.
- Публичные страницы не показывают внутренние украинские переводы. Кабинет имеет lang=uk.
- Цвета темы и стиль заголовков валидируются; некорректные значения отвергаются.
- Выключение секции контактов учитывается также на страницах услуг и объектов.
- Письмо владельцу на украинском, перевод названия услуги, летнее и зимнее время Europe/Helsinki.
- test-admin.cjs проверяет логику 15 вкладок с минимальным DOM mock, пути полей, FI/UK-пары, сохранение подсказок отдельно от FI, CSRF и перевод ошибок. Это проверка логики; она не заменяет браузерный рендер.
- Автономное превью: FI по умолчанию, обе версии и все фотографии внутри HTML; отсутствуют внешние script src и сетевые запросы его сценария.
- PDF-инструкция: 17 страниц, кириллица, команды, все вкладки и словарь; страницы отрендерены и визуально проверены перед упаковкой.

## Практические ограничения проверки

В этой среде нет доступного control-browser для визуального тестирования сайта, поэтому полный visual browser QA и реальные viewport screenshots не выполнены. Адаптивные правила включены для широких экранов, планшетов и мобильных устройств; их нужно окончательно проверить в браузере после локального запуска.

Docker daemon и доступ к вашему Google Cloud/SMTP/рекламным аккаунтам не использовались. Контейнерная сборка в Cloud Build, реальные IAM-разрешения, доставка email, DNS/TLS и приём событий рекламными кабинетами должны пройти проверку в вашей среде. Mock-проверки REST/SDK не заменяют эти проверки.
