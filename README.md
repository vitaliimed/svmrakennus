# Construction website - Go / Cloud Run

Полный проект сайта строительной компании: финский основной язык, английский второй. Админпанель на украинском с редакторскими переводами финского контента. Сайт и админпанель работают на Go; npm-сборка и внешние Go-модули не нужны.

## Быстрый запуск

Требуется Go 1.22 или новее. Для публикации используйте актуальную поддерживаемую версию; Dockerfile использует Go 1.26.

```bash
cd svm-rakennus
go run ./cmd/server
```

Сайт: `http://localhost:8080/fi/`. Английская версия: `http://localhost:8080/en/`. Админпанель: `http://localhost:8080/admin`. Начальный пароль: `12345`; замените его во вкладке «Система» перед публичным запуском.

## Google Cloud Run

В Cloud Shell, из папки проекта:

```bash
bash scripts/bootstrap-gcloud.sh YOUR_PROJECT_ID
bash scripts/deploy-cloud-run.sh
bash scripts/configure-email.sh
```

Первый скрипт создаёт отдельную базу Firestore, закрытый bucket, service accounts и секреты. Второй публикует Go-контейнер. Третий подключает SMTP. После запуска заполните компанию, контакты и домен через админпанель.

## Проверка

```bash
go test -race ./...
go vet ./...
node scripts/test-tracking.cjs
node scripts/test-admin.cjs
python3 scripts/check-content.py
bash scripts/verify.sh
```

`verify.sh` дополнительно требует Node.js и Python 3. Сайт в production требует только собранный Go-бинарник и настройки окружения.

Редактор: 15 вкладок; FI + украинские переводы по умолчанию, английская версия в дополнительных полях. Переводы обновляются вручную, отдельно от публичных текстов. Цвета темы и стиль заголовков доступны в «Компанія та контакти». Скриншоты/visual browser QA необходимо проверить после запуска: браузерные инструменты в среде разработки недоступны.
