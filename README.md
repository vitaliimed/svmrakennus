# SVM Rakennus — Contrast / Go / Cloud Run

Полный проект сайта строительной компании: финский основной язык, английский второй. Админпанель на украинском с редакторскими переводами финского контента. Сайт и админпанель работают на Go; npm-сборка и внешние Go-модули не нужны.

## Быстрый запуск

Требуется Go 1.22 или новее. Для публикации используйте актуальную поддерживаемую версию; Dockerfile использует Go 1.26.9.

```bash
cd svm-rakennus
go run ./cmd/server
```

Сайт: `http://localhost:8080/fi/`. Английская версия: `http://localhost:8080/en/`. Админпанель: `http://localhost:8080/admin`. В локальном режиме начальный пароль: `12345`. Для Cloud Run задаётся отдельный пароль длиной 12–256 символов в Secret Manager.

## Google Cloud Run

Актуальный порядок и результаты сверки: [этап 2](docs/STAGE2-RU.md). В Cloud Shell из `/home/medynikv/sites/svm-rakennus`:

```bash
bash scripts/verify.sh
bash scripts/check-client-project.sh project-c6c1d639-9739-4837-9c8
bash scripts/bootstrap-gcloud.sh project-c6c1d639-9739-4837-9c8
```

Bootstrap готовит именованную Firestore в `europe-north1`, закрытый bucket и секреты. Используются существующие `svm-build` и `svm-runtime`. Сайт на этом шаге не развёртывается. Владелец платёжных реквизитов проверяется клиентом отдельно.

Следующий отдельный шаг — закрытая версия: `bash scripts/deploy-cloud-run.sh --private`. Публичный выпуск после заполнения сайта выполняется явно: `bash scripts/deploy-cloud-run.sh --public`.

## Проверка

```bash
go test -race ./...
go vet ./...
node scripts/test-tracking.cjs
node scripts/test-admin.cjs
python3 scripts/check-content.py
bash scripts/verify.sh
```

`verify.sh` дополнительно требует Node.js и Python 3. Сайт в production требует только собранный Go-бинарник и настройки окружения.

Редактор: 15 вкладок; FI + украинские переводы по умолчанию, английская версия в дополнительных полях. Переводы обновляются вручную, отдельно от публичных текстов. Цвета темы и стиль заголовков доступны в «Компанія та контакти». Проверены FI/EN в Chromium на ширинах 1440, 768, 390 и 360 px, мобильное меню, локальная заявка и вход в кабинет. Скриншоты: [desktop](docs/qa/contrast-desktop.jpg), [mobile](docs/qa/contrast-mobile.jpg). Реальный Cloud Run, Docker/Cloud Build, SMTP и рекламные аккаунты проверяются отдельно после настройки.
